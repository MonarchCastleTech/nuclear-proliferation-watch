Methodology

The index estimates public nuclear-escalation pressure over the next 0–30 days. It does not estimate weaponization, a nuclear test, or the status of any facility. Inputs are public and rules are fixed before each run.

35%

IAEA safeguards strain

Predeclared access, verification, enrichment and non-compliance terms in official IAEA page titles; latest 14 days versus prior periods using median/MAD.

25%

NPWMD designation delta

Exact added and removed entity IDs between accepted official OFAC SDN snapshots, restricted to the NPWMD program.

20%

Facility security incidents

Attack, projectile, sabotage, loss and damage language in the IAEA-hosted Nuclear Events Web-based System.

20%

Test-site seismicity

USGS events score only if shallow M3.5+ within 75 km of a historical test area, or explicitly catalogued as nuclear explosion.

Aggregation. Available components are reweighted to 100%. A five-point concurrence bonus requires both an official indicator and an independent physical indicator above watch. Missing data is not scored as zero. Cached data expires after 72 hours; total IAEA failure preserves the last-good publication.
Critical limitation. Seismic waveforms alone cannot identify a nuclear explosion. CTBTO uses seismic, hydroacoustic, infrasound and radionuclide evidence plus expert review. This dashboard makes no test claim without that verification.
Reproduction. GitHub Actions runs every six hours, tests the model, commits accepted snapshots and output, then deploys the same file shown here. Formulae, evidence, scores and URLs are in data/output.json.
